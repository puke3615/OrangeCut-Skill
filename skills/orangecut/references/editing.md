## Editing Workflow

### Same-project nested sequences

Use an editable inner sequence for captions and pacing, then place it in the outer layout without rendering an intermediate MP4:

```sh
oc sequence list --json
oc sequence create --name "Inner edit" --width 1080 --height 1920 --fps 30 --json
oc timeline add-sequence <inner-id> --sequence-id <outer-id> --at-frame 0 --in-frame 6 --out-frame 96 --muted --json
oc read --sequence-id <outer-id> --frames 0,30 --json
```

Populate the inner sequence before placing it. `--at-frame` uses the outer frame rate; `--in-frame` and exclusive `--out-frame` use the inner rate. Omit `--out-frame` to capture the current inner end at placement time. Omit `--muted` to include the child mix. The time and crop belong to the placement; the contents stay live. Shortening the child content does not ripple the parent: the covered tail becomes blank and silent. Use `--sequence-id` on edit/read/export commands that expose it to target a non-default sequence.

### Non-destructive timeline trimming iron rule

Import the complete original long take. Never physically pre-trim it with FFmpeg before import: the original head and tail must stay available for repairs.

- `oc timeline ripple-delete --from-frame 320 --to-frame 418 --exclude-tracks bgm,paper --dry-run --json` previews a half-open timeline splice across included tracks and sequence markers. Remove `--dry-run` to commit it as one undo step.
- `oc timeline ripple-trim <clip-id> --delta-frames +9 --edge end --exclude-tracks bgm --json` extends the tail. A negative delta shortens and closes the interval. `--edge start` changes the source head while anchoring the timeline start; the tail and downstream content shift. Linked A/V stays together. Out-of-bounds or locked edits fail atomically.
- Exclusions resolve by exact ID, exact custom label or role, kind (including `overlay` for components), then case-insensitive substring. Unmatched selectors are errors. Inspect `summary.excludedTrackIds` before committing.
- `oc media matte <full-source> --output <variant.webm> --in-frame 120 --out-frame 240 --quality high --first-mask <prompt.png> --json` uses source-frame indices, with an exclusive end. The optional high-quality PNG matches the first requested decoded frame's size: white retains the subject, black excludes it. Alpha frames are reusable across ranges with the same settings, including the explicit prompt's frame. Outline changes do not invalidate them. Check `cacheStats`; a full hit avoids inference but still decodes and encodes WebM. `--no-cache` bypasses persistent cache reads and writes.
