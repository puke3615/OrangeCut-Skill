# Optional Capabilities Plugins (OCP)

## License tiers and availability

Follow the [Skill tier rules](../SKILL.md). Run `oc license status --json` before using Pro commands. `oc plugin ls` shows what is installed, not what the license permits. On Community, do not attempt to install or run Pro plugins. If the user needs one, direct them to license management; do not probe access by retrying `PRO_REQUIRED`.

| Tier | Registry entries (21) | Access |
|---|---|---|
| [Community] | `asr`, `fonts` | Built-in offline Chinese Paraformer and open-source fonts for editing and captions. |
| [Pro] | `matting`, `segment`, `inpaint`, `vocal-sep`, `denoise`, `interp`, `upscale`, `tts`, `shots`, `faces`, `ocr`, `diarize`, `clip`, `clap`, `vl`, `douyin`, `fetch`, `product`, `gen-image` | Installation, execution, and cache use are gated by the service. |

The tier applies to semantic commands as well. `fetch` / `douyin` / `product` require network access; `gen-image` uses the user's provider configuration and quota. Pro is not a free cloud service. Community editing, preview, CLI orchestration, and watermark-free `<= 1080p` CPU export do not require Pro plugins. See [Export and jobs](jobs.md) for GPU and larger exports.

## Install on demand

For a capability marked `[Plugin: name]`, check the license, then call its command. On `PLUGIN_NOT_INSTALLED`, follow `remediation` (`oc plugin add xxx`) for the missing plugin and retry. `oc plugin ls [name] --json` lists the full registry, with description, type (`local`, `tool`, or `cloud`), install status, platform support, and disk use. `oc capabilities` includes a summary. `status` is `ready`, `not_installed`, `broken`, or `dev_override`. Use `installDir` to find installed assets. Run `add` again to resume, repair, or upgrade; uninstall with `oc plugin rm <name>`.

`asr`, `fonts`, and the HTTPS-based `gen-image` are cross-platform. The other runtimes in this registry are Windows-only, including CPU-capable `shots`, `ocr`, and `diarize`. On `supported: false`, report `unsupportedReason` and do not attempt installation. Check `supported` before installing NVIDIA-dependent models. Downloads can be several GB. Full-film `shots` and `speakers` have a 90-minute CLI window; other tools can take 15–30 minutes. Do not add a shorter wrapper timeout or assume a quiet process has stalled. If batching, split by source asset. Run GPU plugins and export separately to avoid VRAM contention.

Configure cloud plugins with `oc plugin config <name> --set KEY=VALUE`. Values stay local and are not echoed; upgrades and `rm` preserve them, and `--unset KEY` clears one. On `PLUGIN_NEEDS_CONFIG`, check `requiredSecrets` and `configured`. For any billable plugin, state the approximate cost and number of calls before a batch.

## Cache behavior

Deterministic calls (`shots`, `diarize`, `faces`, `ocr`, `segment`, `matting`, `inpaint`, `upscale`, `interp`, `denoise`, `vocal-sep`) are cached across sessions on the machine. Hits report `cached: true` and `cachedFromSeconds`. Cache identity uses source contents, parameters, and invocation logic, not source or output paths. A hit copies files to the newly requested output path. Generative calls (`gen-image`/`tts`) and live retrieval (`fetch`/`product`) are not cached. Inspect counts and disk use with `oc plugin cache --json`; force a rerun with `oc plugin cache [name] --clear --json`. `OCP_NO_CACHE=1` must be set in the service environment, not just the client's shell. On a 180-frame sample, cold and cached runs took 9.2 s and 0.15 s respectively.

## Semantic commands

- [Pro] [Plugin: shots] `oc media shots <file> [--threshold] [--min-scene-frames] --json`: TransNetV2 detects shot boundaries and returns `scenes/cuts`. Start here when breaking down a source into shots; supports CPU.
- [Pro] [Plugin: faces] `oc media people <file> [--every-n-frames] [--similarity] [--max-frames] --json`: Detects and groups faces into per-person timelines. Use it to find shots of the same performer.
- [Pro] [Plugin: clip] `oc media search-index <file> --index <x.npz>`: Index frame embeddings, then coarse-filter footage with `oc media search "<Chinese prompt>" --index <x.npz> [--top-k]`. Use `vl` to review the shortlist.
- [Pro] [Plugin: vl] `oc media describe --prompt "<problem>" --video <file> --frame <n> | --image <img> --json`: Ask Qwen2.5-VL about a frame or still: content, quality, composition, or whether a face is visible. Budget roughly 8 GB of VRAM and avoid running alongside export.
- [Pro] [Plugin: ocr] `oc media ocr --image <img> | --video <file> --frame <n> --json`: Use PP-OCR to read and locate burned-in captions, cards, or watermarks before removing or replacing text. Runs on CPU.
- [Pro] [Plugin: upscale] `oc media upscale <file> --output <out> [--scale 2|3|4] [--model photo|anime] [--still] --json`: Real-ESRGAN upscaling for low-resolution assets. Photo mode is fixed at 4×; anime mode supports multiple scales.
- [Pro] [Plugin: interp] `oc media interp <file> --output <out.mp4> [--factor 2|4] --json`: RIFE interpolation for smoother slow motion. Retiming alone repeats frames below the source-to-timeline frame-rate threshold. Interpolate first if the repeated frames are objectionable.
- [Pro] [Plugin: vocal-sep] `oc audio separate <file> --output-dir <dir> [--mode two|four] --json`: Demucs separates vocals and accompaniment or creates four stems. Useful for isolating dialogue from a music bed.
- [Pro] [Plugin: diarize] `oc audio speakers <file> [--num-speakers N] [--threshold] --json`: Returns `speaker_N` segments for distinguishing speakers. It measures who speaks when, not who is visible. Runs on CPU.
- [Pro] [Plugin: denoise] `oc audio denoise <in> --output <out> --json`: Clean up hiss and room noise on CPU. See [standalone voice enhancement](audio-enhance.md) for the current service behavior.
- [Pro] [Plugin: douyin] `oc media douyin-works <work/creator profile share URL|Douyin handle|sec_uid> [--limit 20] [--cursor <nextCursor>] --json`: Lists public posts by resolving a share link or creator. Returns `creator` (including `profileUrl`), `videos[]`, `nextCursor`, `hasMore`, and `partial`. Each post includes `awemeId`, `description`, `createTime`, `durationMs`, `coverUrl`, public engagement counts, and `shareUrl`. Pass `nextCursor` as `--cursor` (up to 200 items per page). The query is read-only; use `oc media fetch` with a selected `shareUrl` to download. Managed sessions renew automatically and are encrypted. Run serially and follow `DOUYIN_VERIFICATION_REQUIRED` or `DOUYIN_RATE_LIMITED` rather than retrying concurrently.
- [Pro] [Plugin: fetch] `oc media fetch <url> [--output <file>] [--cookies <jar>] [--audio-only] [--format <expression>] [--url-only] --json`: Downloads authorized source media or audio, preferring watermark-free H.264 by default for downstream compatibility. When the site offers audio but a selected format would be silent, the command fails with `FETCH_SILENT_PICK`; genuinely silent sources return `hasAudio:false`. Douyin short links such as `v.douyin.com/...` work with native web detail, including with explicit `--format` or authorized `--cookies`. A warmed-up response can expose `cookies: "warmed-up"`, `extractor: "DouyinPageDetail"`, and `formatId` such as `normal_1080_0`. If another supported site returns `FETCH_NEEDS_COOKIES`, pass an authorized Netscape export to `--cookies`. Update yt-dlp through the pinned registry URL and SHA-256, then `add`.
- [Pro] [Plugin: product] `oc media product <url> --output-dir <directory> [--cookies <jar>] [--max-images N] --json`: Collects authorized public product-page material into `images/` (main and detail images), `product.json` (title, store, spec table, and image list), and `raw-api.json` (source response). Reads structured page responses rather than inventing claims or prices. `priceAvailable: false` means the price was not available. `PRODUCT_NEEDS_COOKIES` requires an authorized Netscape export; there is no managed login. `PRODUCT_PAGE_UNRECOGNIZED` can include `page-snapshot.html` for inspection.
- [Pro] [Plugin: clap] `oc audio index <media-directory> --index <x.npz>`: Index a sound or music library once, then search it with `oc audio find "<English prompt>" --index <x.npz> [--top-k]`. Write search terms in English.
- [Pro] [Plugin: tts] `oc tts say "<text>" --ref <voice.wav> --output <out.wav> [--lang zh] [--duration-factor] --json`: Synthesizes speech from a reference voice with IndexTTS-2.5. The first run downloads auxiliary models.
- [Pro] [Plugin: gen-image] `oc media genimage "<prompt>" --output <out.png> [--model <model-id>] [--size 1024x1024] [--image <reference>...] --json`: OpenAI Images compatible generation (`images/generations`) and reference editing (`images/edits`, multipart). Configure `oc plugin config gen-image --set IMAGE_API_BASE_URL=<api-base> --set IMAGE_API_KEY=<key>` in the private local configuration, optionally `IMAGE_API_MODEL`. Models and accepted sizes depend on the provider; charges go to that provider. Never echo configured keys.
- [Pro] [Plugin: inpaint] There is no semantic shortcut. Use `oc plugin run inpaint --request <req.json> --timeout 5400` with `{"video": "<absolute-path>", "outputPath": "<out.mp4>", "box": [x, y, w, h]}`. Use a fixed pixel `box` from `oc media ocr` or `oc read`, or `"maskVideo": "<mask-video>"` for a moving mask from `oc media segment` (white means erase). Supply one or the other. ProPainter returns `outputPath`/`seconds` with no audio. Process only the required frames, budget roughly 8 GB VRAM, and restore source audio separately on the timeline.
- [Pro] [Plugin: segment] `oc media segment <file> --output <mask.mp4> (--box x,y,w,h | --point x,y [--point neg:x,y ...]) [--frame N] [--alpha <out.webm>] [--mask-png <out.png>] --json`: SAM 2.1 tracks a prompted object from a box or points on the chosen frame. The main output is a monochrome mask video for `inpaint` via `maskVideo`; `--alpha` yields VP9 with transparency and `--mask-png` saves the prompt-frame mask. Uses roughly 6 GB of VRAM (about 0.2–0.5 s per frame in local tests), and rejects sources over 3000 frames by default. Test each shot separately: hard cuts can break identity. Use `media shots` to find the boundaries; if `framesWithoutObject` is above zero, inspect the missing frames.
- [Community] [Plugin: asr] `oc plugin add asr` installs the cross-platform model package for `oc media transcribe`.
- [Community] [Plugin: fonts] `oc plugin add fonts` installs cross-platform type assets (about 250 MB), including LXGW WenKai and intermediate Source Han/Noto weights beyond the built-in Regular and Black. `oc plugin ls fonts --json` reports `installDir`; look in `<installDir>/fonts/`. Register the selected font with `oc asset import <file> --kind font`, then use `--font-asset-id`. Installation does not import any font into the Project.
- Escape hatch: `oc plugin run <name> --request <req.json> [--timeout seconds]` uses that plugin's request schema. Set `--timeout` for longer tasks rather than wrapping it in a shorter deadline.

## Choose tools by task

- **Source cleanup:** Read soft captions with `media subtitles`; locate burned-in text with `ocr` and remove it with `inpaint` when appropriate. Use `segment` to track moving masks. Clean narration with `denoise` or upscale a low-resolution source with `upscale`.
- **Analysis and search:** Use `shots` for cuts, `people` for faces, `speakers` for dialogue attribution, `search-index`/`search` for a shortlist, `describe` for a closer look, and `ocr` for text.
- **Asset production:** Audition `tts` before a batch. Use `genimage` for covers or cards. Prepare B-roll separately; use `separate` for stems and `index`/`find` to search an audio library.
- **Finishing:** Use `interp` for slow motion and `matte --quality high` for text behind a speaker.

## Public creator lookup

`oc media douyin-creator <work-or-creator> --json` resolves a creator without downloading media or listing works. Read `creator.secUid`, `nickname`, `uniqueId`, `profileUrl`, and, for a work, `sourceWork.awemeId`. Missing profile statistics are null, not zero. Use `oc media douyin-works` for paginated public works and `oc media fetch` for authorized downloads.
